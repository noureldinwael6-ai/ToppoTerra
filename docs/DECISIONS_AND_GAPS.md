# Decisions and gaps

- NOAA product metadata and actual rows govern coverage. Arizona and California replace the illustrative prototype regions. NOAA nClimDiv is a statewide estimate, with NOAA station inputs and NOAA spatial processing.
- Apply whole-calendar-year inference and give monthly views separate display controls. Use a dated local bundle and compute changes from the current selection.
- Transfer Euclidean delay embeddings and persistent homology. Climate TDA needs null calibration and independent validation before inferential use. The legacy sensor-specific metric and deployment code stay outside the climate pipeline.
- Use native browser modules and Node rather than the prototype's dependencies. This permits an offline demonstration from the project directory and a static production build.
