# ToppoTerra design system

ToppoTerra adopts the reference storyboards' globe-led entry, map-led selection and separate scientific lab. The design uses a dark observatory backdrop, restrained mint emphasis, oversized editorial typography and a chart-first visual hierarchy. The project wordmark is consistent across views. Public Explorer uses a broad chronological figure next to an interpretive rail, then puts uncertainty beside geographic coverage. The Research Lab pairs a projection viewport with an observation inspector, followed by analytical comparisons. Benchmark results use aligned columns for paired metrics and separate color cues for measured, conventional and exploratory evidence.

| Element | Convention |
| --- | --- |
| Canvas and panels | Obsidian `#091217`, blue-green `#0f1b22`, hairline `#253c42`. Borders separate controls and findings. Most explanatory copy lives directly on the canvas. |
| Text | Off-white `#eef4ee`, muted `#a8bab9`. Uppercase metadata in a compact monospace. Serif display headings at roughly 54–139 px on desktop and 44–64 px on a phone. System sans at 15–18 px for controls and prose. Use tabular numerals for axis and statistic labels. |
| Primary evidence/interaction | Mint `#a9ebca` for the primary action and first observed series. |
| Comparison and trend | Amber `#edb688` for the comparison channel or trend fit, with labels and distinct dash/marker patterns when a shared chart needs both. |
| Experimental | Lavender `#c8b3fa` for Topo-Signal results and experimental labels. |
| Spacing | Fluid 16–64 px page gutters, 8 px control spacing, 24–64 px section spacing. Section columns collapse to one stack on small screens. |
| Interaction | Primary and secondary controls use a visible focus outline. Region selection has text, check state and color. Preserve 44 px pointer targets for core actions. Keyboard buttons can rotate or pause the Earth. |
| Motion | Quiet route entrances and a capped initial Earth orbit. Globe animation pauses outside the viewport and while the page is hidden. Reduced-motion views use a still poster and suppress transitions. |
| Chart semantics | Include units, coverage and source where relevant. Axes, labels, and hover/focus detail describe the same evidence. Style comparison and inference separately from the observed series. |
