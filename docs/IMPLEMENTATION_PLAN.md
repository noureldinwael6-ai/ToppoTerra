# Phase 1 implementation plan

1. Regenerate a compact Arizona/California monthly dataset from the supplied NOAA product tables, with input cross-checks, calendar rules and provenance. Audit the NASA archive separately.
2. Build a static browser app using native ES modules and a small Node launcher. Use the prototype's screen progression and the supplied Earth texture. Replace its illustrative seed data and provisional topology with reproducible calculations.
3. Make statewide trend, confidence, seasonality and comparison the default. Run delay embedding and Rips H0/H1 in a worker with cached settings. Show the evidence side by side.
4. Connect history and export. Check real routes and interactions in Chromium, including desktop, tablet and phone viewports. Keep the package portable and stop after the Phase 1 handoff.
