# Scientific differentiation

TopoTerra tests whether adding H1 bottleneck distance to the same climate analog estimator changes reconstruction error. The contribution is the integration and paired empirical test, using known delay embedding, persistent homology and nearest-neighbor methods. Fixed archive trials show both wins and losses. A reliable overall gain is unestablished. See [protocol](PROOF_LAB_PROTOCOL.md) and [measured results](BACKTEST_RESULTS.md).
